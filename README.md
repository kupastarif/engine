# engine | si tukang ngitung tarif


🚗 Engine Ride-Hailing

Mesin kalkulasi biaya dan tarif ride‑hailing berbasis JavaScript
Porting dari spreadsheet Excel v9.7k masterapp.xlsx ke kode yang bersih, modular, dan siap pakai.

Engine ini adalah inti logika bisnis untuk menghitung:

· Tarif perjalanan (online / offline)
· Biaya operasional kendaraan (BBM, perawatan, depresiasi, pajak, atribut)
· Pendapatan bersih driver dan aplikasi
· Proyeksi pendapatan bulanan
· Perbandingan dengan transportasi umum (angkot, TransJakarta)
· Status dan badge (aman, warning, serakah, dll.)


🚀 Fitur Utama

· Multi‑kendaraan: Mobil (1000cc, 1500cc, 2000cc, Listrik) & Motor (125cc, 160cc, 200cc, Listrik)
· Multi‑layanan: Hemat, Standar, XL, Prioritas, Premium, Premium XL
· Mode Online & Offline (dengan berbagai skenario tarif)


Dibuat dengan ekosistem ride‑hailing Indonesia.
